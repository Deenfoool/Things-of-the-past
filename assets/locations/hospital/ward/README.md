# Больница — палата Алексея Архипова

Локация дела `lyublino-1994`.

Структура комнаты следует общему правилу игры: **4 направления = 3 интерактивные стены + 1 дверь/выход**.

Код `case-001-hospital.js` автоматически проверяет наличие всех четырёх PNG. Пока хотя бы одного файла нет, больница отображается в списке выездов как локация, ожидающая фоновые сцены. Когда все четыре файла появятся, комната регистрируется автоматически.

## Обязательные файлы

1. `01-bed.png` — главная стена: койка Алексея Архипова. Основная зона разговора со свидетелем.
2. `02-window.png` — окно, прикроватная тумба, спокойная больничная обстановка.
3. `03-sketch-table.png` — стол/место, где следователь составляет предварительный фоторобот.
4. `04-door.png` — дверь из палаты; выход обратно к системе выездов/в дежурную часть.

## Визуальный стиль

- Москва / постсоветская больница середины 1990-х;
- обычная государственная палата, функциональная, не заброшенная;
- выцветшие кремовые/светло-зелёные стены, старая краска, линолеум;
- металлическая больничная мебель, простое постельное бельё, тумба, графин/стакан, старые выключатели и розетки;
- дневной свет + мягкое больничное потолочное освещение;
- hand-painted 2D point-and-click background, slightly stylized realism;
- muted beige, pale green, grey, cream palette;
- straight-on eye-level first-person view, natural 40–50 mm perspective;
- камера близко к стене, без wide-angle/fisheye;
- одинаковые пропорции, свет, высота камеры и стиль на всех четырёх стенах;
- 16:9;
- без UI и читаемого текста.

## Архипов

Свидетель подключён как отдельный NPC overlay из `assets/characters/hospital/arkhipov-ward/`. Кадры `resting`, `speaking`, `recalling` и `tired` имеют прозрачный фон и независимые transform-настройки в F2 → NPC. Внешность не фиксирует точную локализацию ранения, поскольку публичные источники в этой детали расходятся.

## Фоторобот

Сам реалистичный портрет преступника в фон не встраивать. `case-001-hospital.js` содержит отдельный интерактивный интерфейс предварительного фоторобота. На этой стадии канонически фиксируются только опубликованные приметы: молодой мужчина, тёмные волосы, белый свитер с рисунком, голубые джинсы; точные черты лица остаются неопределёнными.
